# **App Name**: CyberWise

## Core Features:

- Cybersecurity Awareness Articles: Provides access to articles and guides to enhance cybersecurity awareness.
- Cybersecurity News Feed: Aggregates worldwide cybersecurity news from various sources.
- Password Strength Analyzer: Analyzes the strength of user-inputted passwords, providing feedback and suggestions for improvement.
- Phishing Awareness Simulator: Simulates phishing emails to educate users on how to identify and avoid phishing attempts.
- AI-Powered Password Suggestion: Suggests strong, unique passwords using an AI tool.
- Account Recovery Assistance: Guides users through the process of recovering lost accounts.
- Cybersecurity Advice Generator: LLM tool offers users customized cybersecurity advice based on their digital habits and potential vulnerabilities.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) for a modern, tech-focused feel.
- Background color: Dark gray (#2E2E2E) to provide a sleek, secure backdrop.
- Accent color: Lime green (#32CD32) for highlighting key information and interactive elements.
- Headline font: 'Space Grotesk' (sans-serif) for a computerized, techy feel; use 'Inter' for body text (sans-serif, neutral look)
- Use a consistent set of minimalist icons related to cybersecurity topics.
- Employ a clean and structured layout to ensure easy navigation and readability.
- Subtle transitions and animations to enhance user experience.
